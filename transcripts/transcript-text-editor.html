Transcript Text Editor

Edit dialogue, delete unwanted lines, add new lines. Export when done.

How to use: Click any line to edit the text directly. Click the colored name badge to toggle the speaker (cycles through all speakers). Click ✕ to mark a line for deletion (click the badge again to restore it). Use + Add line buttons to insert new rows. When finished, click "Export Changes" and paste into Claude to update the transcript.
